# screenkit для android

Приложение `apps/mobile` — это android-клиент библиотеки вставок. Оно читает ту же
библиотеку и то же облако, что и сайт: разговаривает с маршрутом `/api/rpc` по
ConnectRPC и берёт контракты из рабочего пакета `@mixture/protocol`, а доменные типы —
из `@screenkit/core`. Своего бэкенда у приложения нет.

## Что внутри

| Экран              | Маршрут                     | Что делает                                                                 |
| ------------------ | --------------------------- | -------------------------------------------------------------------------- |
| Разрешение на папку| `src/app/onboarding.tsx`    | объясняет, что будет прочитано, открывает системный выбор папки, «пропустить пока» |
| Библиотека         | `src/app/(tabs)/library.tsx`| поиск, фильтр по категориям и избранному, карточки, долгое нажатие          |
| Превью             | `src/app/(tabs)/preview.tsx`| рамка устройства: сайт в webview, файл в плеере, сцена — паспортом          |
| Облако             | `src/app/(tabs)/cloud.tsx`  | файловый менеджер: облако и локальная папка, список/сетка, меню по долгому нажатию |
| Настройки          | `src/app/(tabs)/settings.tsx`| схема, палитра, язык (ru/en/snark), адрес сервера, токены, папка           |
| Мастер вставки     | `src/app/wizard/*`          | пять шагов с прогрессом, «назад/далее» и черновиком в AsyncStorage          |

Раскладка исходников:

```
src/app        маршруты expo-router (вкладки, мастер, карточка вставки)
src/components примитивы (Surface, Pill, SegmentedControl, IconTile), карточки, bottom sheet
src/lib/rpc    транспорт connect, кодек protobuf → домен, полифиллы
src/lib/local  папка через StorageAccessFramework
src/theme      токены из apps/web/app/globals.css: палитры, радиусы 12/16/24, моноширинный шрифт
src/wizard     черновик, провайдер и хром мастера
src/i18n       ru / en / snark с одинаковым набором ключей
```

## Транспорт: connect, а не gRPC-Web

Браузер ходит в `/api/rpc` бинарным gRPC-Web. В react native так нельзя: `fetch` не
отдаёт `response.body` потоком, а gRPC-Web читает ответ именно потоком кадров. Поэтому
приложение говорит по **протоколу Connect** (по умолчанию — бинарный protobuf): унарный
вызов читает `response.arrayBuffer()`, что react native умеет. Роутер на сервере уже
принимает оба протокола, менять его не нужно.

Формат (`binary` / `json`), адрес и таймаут меняются во вкладке «настройки». Токены
(`x-mixture-edit-token`, `x-mixture-cloud-token`, `x-mixture-cloud-key`) хранятся только
на устройстве и подставляются интерсептором в каждый запрос.

## Локальные файлы

Android даёт доступ к одной папке за раз — через Storage Access Framework. Приложение
запрашивает её на экране онбординга, запоминает `content://`-uri в настройках и потом
показывает содержимое рядом с облаком. Файлы никуда не загружаются: читаются имена,
размеры и типы, а содержимое — только когда вы открываете файл или отправляете его в
облако.

## Разработка

```bash
pnpm install                       # из корня репозитория
pnpm --filter mobile typecheck     # обязательный локальный шлюз
npx expo-doctor                    # из apps/mobile; тот же шаг гоняет CI на PR
pnpm --filter mobile start         # metro; нужен dev client или expo go
```

`metro.config.js` смотрит на корень репозитория и включает
`unstable_enablePackageExports` — `@mixture/protocol` отдаёт `.ts` по подпутям
`./library` и `./cloud`, без сборки.

`react` и `react-dom` закреплены на `19.2.7` — на версии, которую уже разрешает
монорепозиторий. Expo для SDK 57 предлагает `19.2.3`, но тогда в дереве оказываются две
копии react, и `expo-doctor` ругается на дубликат нативной зависимости. Поэтому `react`,
`react-dom` и `typescript` (он закреплён на 5.7.3 общим `tsconfig.base.json`) внесены в
`expo.install.exclude` в `apps/mobile/package.json`.

pnpm по умолчанию раскладывает `node_modules` символьными ссылками, а автолинковка
react native и gradle ждут плоское дерево. `apps/mobile/.npmrc` включает
`node-linker=hoisted` для команд, запущенных **из этой папки**; сборка APK в CI ставит то
же самое переменной `NPM_CONFIG_NODE_LINKER=hoisted`, чтобы не менять раскладку всего
репозитория. Установка из корня (`pnpm install`) остаётся обычной, и веб-сборка её не
замечает.

## Сборка APK

APK собирает `.github/workflows/mobile.yml`: `workflow_dispatch` и теги `v*`. Шаги —
`pnpm install`, `npx expo prebuild --platform android`, затем `./gradlew assembleRelease`
в `apps/mobile/android`; готовый файл выкладывается артефактом сборки.

Каталоги `android/` и `ios/` не коммитятся: их каждый раз генерирует `expo prebuild`.

### Настоящий ключ подписи

Без секретов workflow создаёт одноразовый keystore, чтобы артефакт можно было поставить
на устройство для проверки. Такой APK нельзя публиковать и им нельзя обновить уже
установленное приложение. Для настоящей подписи добавьте секреты репозитория:

| Секрет                      | Что это                            |
| --------------------------- | ---------------------------------- |
| `ANDROID_KEYSTORE_BASE64`   | ваш `.jks`, закодированный в base64 |
| `ANDROID_KEYSTORE_PASSWORD` | пароль хранилища                    |
| `ANDROID_KEY_ALIAS`         | алиас ключа                         |
| `ANDROID_KEY_PASSWORD`      | пароль ключа                        |

Закодировать хранилище: `base64 -w0 release.jks`. Если `ANDROID_KEYSTORE_BASE64` задан,
workflow берёт его и одноразовый ключ не создаёт.

## Чего в приложении нет

- **Сцены вставок не портированы.** Пакеты `packages/inserts/*` — это react-компоненты
  для веба. Вставка типа `scene` показывает паспорт и промпты, а не рисунок; типы `site`
  и `file` отрисовываются по-настоящему.
- **`kind` и `source` не уходят на сервер.** В `mixture/library/v1` у `AddInsertRequest`
  этих полей ещё нет, поэтому мастер сохраняет их в черновике и на шаге проверки
  показывает, но `AddInsert` отправляет только то, что описано в контракте. Когда поля
  появятся в `.proto`, их нужно добавить в `addInsert()` в `src/lib/library.tsx`.
- **Перемещение и переименование — только в облаке.** SAF не даёт expo переименовать
  документ, поэтому для локальных строк эти пункты меню выключены.
- **iOS не собирается.** `app.json` объявляет только android.
