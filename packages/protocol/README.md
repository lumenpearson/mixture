# @mixture/protocol

Protobuf contracts for mixture and the TypeScript bindings generated from them.

- `proto/mixture/common/v1` — shared enums and localized text
- `proto/mixture/library/v1` — the insert library (`LibraryService`)
- `proto/mixture/changelog/v1` — live GitHub changelog (`ChangelogService`)
- `proto/mixture/cloud/v1` — cloud drive over a private GitHub repository (`CloudService`)

Bindings are generated by [buf](https://buf.build) with `protoc-gen-es` into `src/gen`
and are committed. After editing any `.proto`:

```bash
pnpm --filter @mixture/protocol generate
pnpm check:protocol-generation
```

Transport is ConnectRPC over gRPC-Web (binary) served by the Next.js route
`apps/web/app/api/rpc/[...path]`. The package carries no runtime logic.
